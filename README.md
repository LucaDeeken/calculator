# Calculator

A basic calculator app built with HTML, CSS, and JavaScript. Part of The Odin Project Foundations Course and build in August 2024.

## Tasks
- Functions for add, subtract, multiply, divide  
- HTML buttons for digits, operators, clear, equals  
- Display that updates with user input and results  
- Logic for one operation at a time (e.g. 12 + 7 = 19)  
- Rounds long decimals for cleaner display
- Decimal point input  

Live Demo: https://lucadeeken.github.io/calculator/
